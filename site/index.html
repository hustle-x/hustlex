Questions, answered

Which agents does it work with?

Claude Code and Codex today, and any CLI agent you can run in a terminal.

Is it really free?

Yes. Downloading and using hustleX is free.

Do I need an account with you?

No. Your accounts are the ones you already use with your agents.

Can I run sessions on a server?

Yes. Add a remote host and open sessions on it from the same window.

Where does my data live?

On your machine and the hosts you add. Nothing is sent to a hustleX server.
